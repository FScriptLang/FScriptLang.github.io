Practice one new idea at a time, then combine it with the skills you already have. Start with language-only examples; use host integrations when they match your project.

| Progression | What to try | Prerequisites |
| --- | --- | --- |
| Work with inputs and branches | [Hello and FizzBuzz](./guided-examples.md#1-hello-with-script-arguments) | Quickstart and basic pattern matching. Console output needs `IO`. |
| Transform and model data | [Collections and recursive records](./guided-examples.md#3-collections-and-pattern-matching) | Lists, functions, options, and records. |
| Organize a program | [Imports and exports](./guided-examples.md#5-imports--exports-multi-file) | File execution and source aliases. |
| Keep everyday code concise | [Common Script Patterns](./common-patterns.md) | Options, maps, and unions. |
| Put a rule inside an app | [Embedded pricing](./guided-examples.md#6-an-embedded-pricing-rule) | The Embedded overview and Node.js. |
| Use a typed native provider | [FFI graphics: a rotating teapot](./ffi-graphics.md) | Advanced extension setup and the walkthrough's platform requirements. |
| Coordinate concurrent work | [Parallel quicksort](https://github.com/FScriptLang/FScript/blob/main/samples/parallel-quicksort.fss) | Tasks and Concurrency; grant `Threading`, plus `IO` for output. |
| Inspect sharing risks | [Task-sharing samples](../learn/task-sharing-analysis.md#try-the-runnable-samples) | Typed FFI and concurrent tasks. |

The website owns these guides; runnable repository samples live in [FScript's samples directory](https://github.com/FScriptLang/FScript/tree/main/samples). Follow each sample's setup and manifest rather than assuming it has the same capabilities as the first pure script.

If a sample feels like too big a jump, return to the matching [Language Tour](../learn/language-tour.md) chapter or [Advanced](../advanced/overview.md) guide. The library reference is available whenever you need an exact operation.
